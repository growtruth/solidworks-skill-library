# 零件建模知识基线（官方文档蒸馏）

> 依据 SOLIDWORKS 官方帮助文档整理，每条规则后标注来源。官方未明确写出的推论均标注“推论”。

## 1. 建模总原则：先设计意图，再动手

- **特征父子关系**：后建特征依赖先建特征，父特征改动会向下传递。首特征（基体）的可编辑性最差，选错了后面很难改。 → 首特征要选“最稳定、最能代表零件主体形状”的那个。
- **设计意图（Design Intent）**：建模不是画死尺寸，而是规划“改一个尺寸后模型应该怎么变”。可用手段：草图几何关系、草图尺寸、特征的起始/终止条件、阵列参数、方程式、配合方案、骨架草图（Base part technique）。
  - 来源：[Efficient SOLIDWORKS Modeling SolidPractices](https://3dswym.3dexperience.3ds.com/wiki/solidworks-news-info/efficient-solidworks-modeling-solidpractices_aGgKRBg_T16hrkzsbwUBsQ)
- **特征顺序**：FeatureManager 设计树里拖动项目即可改变重建顺序，顺序影响重建结果。 → 次要特征（孔、槽）尽量放在主体和拔模之后。
  - 来源：[FeatureManager 设计树概述](https://help.solidworks.com/2025/chinese-simplified/SolidWorks/sldworks/c_featuremanager_design_tree_overview.htm)

## 2. 草图：状态决定模型是否“可控”

| 状态 | 含义 | 处理 |
|---|---|---|
| 完全定义 | 所有直线/曲线及其位置由尺寸或几何关系（或两者）定义，实体变黑 | 目标状态，工业模型必须做到 |
| 欠定义 | 还缺尺寸/关系，实体为蓝色 | 继续加尺寸或关系 |
| 过定义 | 存在冲突或多余尺寸/关系，实体变红 | 删除冲突关系或把多余尺寸改为从动 |
| 无法求解 | 几何不自洽，粉红显示 | 回退到上一个可解状态重画 |

- 草图完全定义后仍可添加“逻辑上冗余”的几何关系（平行、垂直、等长），系统可容忍。
  - 来源：[草图状态规则](https://help.solidworks.com/2026/chinese-simplified/SolidWorks/Sldworks/c_Sketch_Status_Conventions.htm)、[Sketch States](https://help.solidworks.com/2018/english/solidworks/acadhelp/c_Sketch_States_AcadHelp.htm)
- 尺寸默认是**驱动尺寸**；两个尺寸驱动同一几何体属于非法，需要把其中一个改为从动。
- 草图必须闭合才能做凸台/基体拉伸或旋转。
  - 来源：[使用拉伸或旋转凸台/基体绘制草图](https://help.solidworks.com/2026/chinese-simplified/SolidWorks/sldworks/t_sketching_bosses_bases.htm)

## 3. 旋转特征（轴、法兰、端盖的首选）

官方规则（逐条）：
1. 轮廓草图必须是 **2D 草图**，3D 草图不能做轮廓；但**旋转轴可以是 3D 草图**。
2. **轮廓不能与中心线交叉**。
3. 草图里有多条中心线时，必须**明确指定**用哪一条作旋转轴。
4. 旋转曲面和旋转薄壁特征：草图**不能位于中心线之上**。
   - 来源：[Revolves](https://help.solidworks.com/2024/english/Solidworks/sldworks/c_Revolves_Folder.htm)、[旋转特征](https://help.solidworks.com/2010/chinese-simplified/SolidWorks/sldworks/LegacyHelp/Sldworks/Features/Revolved_Base_Boss.htm)
5. API 调用顺序：先选草图（标记 0），再选轴（标记 4 或 16），再 `FeatureRevolve2`。
   - 来源：[FeatureRevolve2](https://help.solidworks.com/2026/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IFeatureManager~FeatureRevolve2.html)

> 实测补充：本机脚本中即使不显式选中草图/轴，只要草图是最后创建的，`FeatureRevolve2` 也能成功（体积校验一致）。但这是**依赖内部状态的脆弱写法**，正式脚本仍应显式选择。

## 4. 拉伸与切除

- 起始条件可选：草图基准面 / 曲面·面·基准面 / 顶点 / 等距；部分起始条件只对第一个实体特征有效。
  - 来源：[拉伸 PropertyManager](https://help.solidworks.com/2020/chinese-simplified/SolidWorks/sldworks/r_extrude_propertymanager.htm)
- 用“所选轮廓”可以从部分草图或开放轮廓生成特征。
- **切除方向的官方定义**：切除的默认方向与草图法线**相反**；凸台默认沿草图法线方向。设置方向参数为 true 即反向。
  - 来源：[FeatureCut4](https://help.solidworks.com/2026/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IFeatureManager~FeatureCut4.html)
- `NormalCut` 参数只对钣金件有效，普通零件必须传 false，否则特征会失败（实测踩坑）。

## 5. 圆角与倒角：顺序比参数更重要

官方建议：
1. **先加大的圆角，再加小的圆角**（多个圆角汇交于一点时尤其如此）。
2. **先拔模，后圆角**：铸件/注塑件有大量圆角与拔模面时，先做拔模特征。
3. **装饰性圆角留到最后**：放得越早，重建越慢。
   - 来源：[圆角概述](https://help.solidworks.com/2022/chinese-simplified/solidworks/sldworks/c_fillet_overview.htm)、[Fillet Overview](https://help.solidworks.com/2024/english/Solidworks/sldworks/c_fillet_overview.htm)

推论（工程经验，非官方原文）：倒角通常放在圆角之前、切除之后，因为倒角依赖清晰的棱边；键槽、孔口倒角要跟着孔特征一起做。

## 6. 阵列

- 圆周阵列需要指定一根轴：可先用“视图 > 隐藏/显示 > 临时轴”显示系统轴，再选它作为阵列中心轴。
  - 来源：[创建圆周阵列](https://help.solidworks.com/2024/chinese-simplified/swconntutorial/t_tut_introsw_create_circ_pattern.htm)、[圆周阵列 PropertyManager](https://help.solidworks.com/2026/chinese-simplified/SolidWorks/sldworks/HIDD_CPATTERN.htm)
- 阵列参数可写方程式，例如把间距写成 `=360/实例数`，实例数一变角度自动跟随——这是典型的设计意图写法。
  - 来源：[在阵列中使用方程式](https://help.solidworks.com/2024/Chinese-Simplified/swconntutorial/t_tut_pattern_useequation.htm)
- API：`FeatureCircularPattern4(实例数, 间距, 反向, 角度尺寸名, 几何体阵列, 等间距, 变化实例)`；选择标记：轴 = 1，被阵列特征 = 4。
  - 来源：[FeatureCircularPattern4](https://help.solidworks.com/2024/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IFeatureManager~FeatureCircularPattern4.html)

## 7. 几何正确性判据（工业交付标准）

| 判据 | 方法 |
|---|---|
| 尺寸正确 | 包围盒/质量属性与图纸逐项核对 |
| 体积正确 | 解析体积 vs `CreateMassProperty2().Volume`，偏差 ≤0.1% |
| 拓扑正确 | 实体数量=1（除非设计就是多实体），无零厚度、无自相交 |
| 可制造 | 壁厚均匀、圆角/倒角可加工、孔位不与边缘过近 |
| 可交换 | 导出 STEP，能被第三方软件读入（首行 `ISO-10303-21;`） |

## 8. 本项目已落地的方法论（一句话版）

> 回转类零件（轴、法兰、端盖）：**一个旋转特征定主体 → 切除做孔槽 → 阵列做重复结构 → 圆角倒角收尾 → 体积校验 → 导出 STEP**。
