# 避坑清单（SolidWorks 建模 + 本机脚本）

> 每条格式：现象 → 原因 → 解法。只收录真实踩过的坑或官方明确规则。

## 一、建模层面

1. **旋转失败 / 体积为 0**
   - 原因：轮廓与中心线交叉，或草图不是 2D 草图，或选了错误的中心线。
   - 解法：轮廓整体放在中心线一侧；草图里只保留一条中心线；确认草图为 2D。

2. **半径写成直径**
   - 现象：体积正好是理论值的 4 倍或 1/4。
   - 解法：旋转轮廓一律用半径；图纸给的是直径就先除以 2。

3. **切除特征返回空、体积不变**
   - 原因：切除默认方向与草图法线相反，刀没切到材料。
   - 解法：反转方向（API `FeatureCut4` 第 3 参数 `Dir=True`）。

4. **普通零件用了 `NormalCut=True`**
   - 原因：该参数只对钣金件有效。
   - 解法：非钣金零件必须传 false。

5. **圆角失败/重建变慢**
   - 原因：圆角顺序不对（先小后大、先圆角后拔模、装饰圆角放太早）。
   - 解法：先拔模 → 大圆角 → 小圆角 → 倒角 → 装饰圆角最后。

6. **草图过定义（变红）**
   - 原因：同一几何被两个驱动尺寸约束，或关系冲突。
   - 解法：保留一个驱动尺寸，其余改为从动；用“显示/删除几何关系”清理冲突。

7. **孔位画在错误平面，孔变成斜孔**
   - 原因：轴向孔必须画在与孔轴垂直的基准面上。
   - 解法：轴线沿 Y 的孔 → 用上视基准面（XZ）；轴线沿 Z 的孔 → 用前视基准面（XY）。

## 二、本机脚本层面（VBScript + SolidWorks 2025）

8. **PowerShell 调 SolidWorks 全部报 `TYPE_E_ELEMENTNOTFOUND`**
   - 原因：本机 IDispatch/.NET 绑定异常。
   - 解法：只用 VBScript（`cscript //nologo`），不要浪费时间试 PowerShell。

9. **`OpenDoc6` 报“类型不匹配”**
   - 原因：ByRef 输出参数在 VBScript 里无法正确传递。
   - 解法：脚本一次跑完“新建→建模→校验→保存”，不要依赖重新打开文档。

10. **`SaveAs2` 返回 0 但文件已生成**
    - 原因：返回值在 VBScript 中不可靠。
    - 解法：用 `FileSystemObject.FileExists` 判断是否成功。

11. **画了 6 个圆，草图里只有 1 个**
    - 原因：坐标用成了模型空间坐标；上视基准面草图必须传 `(x, z, 0)`，第三位保持 0。
    - 解法：草图坐标一律用局部坐标；前视基准面 `(x, y, 0)`，上视基准面 `(x, z, 0)`。

12. **`Set c = sm.CreateCircle 0,0,0,...` 语法报错或静默失败**
    - 原因：VBScript 函数调用带 `Set` 时必须加括号。
    - 解法：`Set c = sm.CreateCircle(0,0,0,0.007,0,0)`。

13. **`UBound(bodies)` 报错**
    - 原因：SolidWorks 返回的 dispatch 数组在 VBScript 中不支持 `UBound`。
    - 解法：用 `For Each` 计数，或者直接用体积/包围盒判断几何。

14. **尺寸差 1000 倍**
    - 原因：API 单位是米。
    - 解法：毫米数值统一除以 1000；体积输出时再乘 1e9 转 mm³。

15. **特征名/草图名写死英文导致选择失败**
    - 原因：GB 模板生成的名称是中文（“草图1”“前视基准面”）。
    - 解法：不要硬编码；遍历特征取 `GetTypeName2()="RefPlane"` 的第 1/2/3 个基准面。

16. **圆周阵列创建成功但数量不对/选不中轴**
    - 原因：选择标记用错，或阵列轴传了非圆边；等间距模式下间距参数含义变化。
    - 解法（实测可用）：先选被阵列特征，类型 `BODYFEATURE`、标记 **4**；再选一条同心圆边 `("", "EDGE", x,y,z, True, 1, ...)`、标记 **1**；等间距时 `Spacing` 传总角度（360° = 6.2831853071796），`EqualSpacing=True`。

17. **`InsertFeatureChamfer` 返回特征但体积不变（倒角没挂上边）**
    - 现象：`GetFeatureCount` 增加、返回非 Nothing，但质量属性体积完全不变。
    - 原因：边选择未真正挂到倒角特征上（特征是空壳，`EdgeCount=0`）。
    - 解法：本机 2025 SP5 未解决；**改用旋转剖面里画 2×45° 倒角**（几何等价、体积可解析校验）。倒角特征 API 待后续用 `IChamferFeatureData2` 或 GUI 宏验证。
