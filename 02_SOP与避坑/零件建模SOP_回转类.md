# 回转类零件建模 SOP（轴 / 法兰 / 端盖）

> 适用范围：以旋转特征为主体的零件。脚本实现见 `03_实战项目/01_法兰盘/build_flange.vbs`，它同时是本 SOP 的可执行模板。

## 步骤 0：读图与规划（不碰鼠标）

1. 找出**回转轴**和**对称面**。回转类零件的第一个特征几乎总是旋转凸台。
2. 把图纸尺寸拆成三类：
   - 轴向尺寸（各段长度）→ 旋转轮廓的水平方向
   - 径向尺寸（各段直径）→ 旋转轮廓的竖直方向（用半径）
   - 孔/槽位置（分布圆直径、角度）→ 切除草图
3. 先算**解析体积**，作为后面校验的基准。公式：
   - 回转体：`V = π × Σ(r_i² × L_i)`
   - 圆柱孔：`V_hole = π × r² × 深度`
4. 确定首特征：优先选“包含最多主要尺寸的那个截面”（如法兰的整个半剖轮廓）。

## 步骤 1：旋转基体

1. 选前视基准面（或与轴线垂直的基准面）新建草图。
2. 先画**中心线**（旋转轴），再画闭合轮廓。
3. 轮廓规则（官方）：
   - 必须是 2D 草图；
   - 轮廓不能与中心线交叉；
   - 草图内有多条中心线时必须指定旋转轴。
4. 标尺寸到完全定义（实体变黑），退出草图。
5. 旋转 360°。
6. **立刻校验体积**：与步骤 0 的解析值对比，偏差 >0.1% 就停下来查（通常是半径写成了直径、或中心线选错）。

## 步骤 2：主要切除（孔、槽、内腔）

1. 孔所在平面 = 与孔轴线垂直的基准面（轴向孔用上视基准面）。
2. 草图坐标用**草图局部坐标**：上视基准面传 `(x, z, 0)`。
3. 切除方向：默认与草图法线相反，切不到材料时把方向反转（API 为 `Dir=True`）。
4. 通孔优先用“完全贯穿”，不要用“给定深度”凑数。
5. 再次校验体积：减去所有孔的体积。

## 步骤 3：重复结构（阵列）

1. 圆周阵列的轴优先选**临时轴**（视图 > 隐藏/显示 > 临时轴）。
2. 实例数与角度建议写成方程式（如 `=360/6`），保证改数量时角度自动更新。
3. 若阵列失败，先检查：被阵列特征是否在阵列轴的同侧、是否跨越了实体边界。

## 步骤 4：收尾特征（倒角、圆角、抽壳）

顺序（官方建议 + 工程惯例）：
1. 拔模（如有）
2. 大圆角 → 小圆角（多个圆角汇交时先做大圆角）
3. 倒角（孔口、轴端）
4. 装饰性圆角放最后（越晚加，重建越快）

## 步骤 5：校验与交付

| 检查项 | 合格标准 |
|---|---|
| 体积 | 与解析值偏差 ≤0.1% |
| 包围盒 | 与图纸最大外形尺寸一致 |
| 实体数 | 1（非多实体设计） |
| 特征树 | 无报错、无“重建模型错误” |
| STEP | 文件存在，首行 `ISO-10303-21;` |
| 命名 | `零件名_关键尺寸.SLDPRT` |

## 步骤 6：复盘（每次建模必做）

1. 记录踩到的坑（现象 → 原因 → 解法）。
2. 补充知识库中缺失的官方规则。
3. 把可复用的操作固化成脚本模板或检查清单条目。

## 脚本模板骨架（VBScript）

```vbscript
Set sw = CreateObject("SldWorks.Application")
Set part = sw.NewDocument("C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2025\templates\gb_part.prtdot", 0, 0, 0)
' 取基准面名：遍历 FirstFeature/GetNextFeature，按 GetTypeName2()="RefPlane" 顺序取第 1/2/3 个
' 画草图 → InsertSketch True 退出 → FeatureRevolve2 / FeatureCut4
' 校验体积：part.Extension.CreateMassProperty2().Volume * 1e9
' 保存：part.SaveAs2(path, 0, False, False)（返回值不可信，用 FileExists 判断）
```
