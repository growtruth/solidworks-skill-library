# SolidWorks Skill Library

SolidWorks 零件建模技能库：把官方文档规则、可复现的建模脚本、工程文件与复盘记录放在一起，目标是让每一次建模都能被验证、被回溯、被复用。

## 目录结构

```
00_能力基线/    环境版本、自动化通道限制、能力边界
01_知识库/      按模块整理的官方规则（零件 / 装配 / 工程图）
02_SOP与避坑/   标准操作流程与踩坑清单
03_实战项目/    可运行的建模脚本 + SLDPRT + STEP
04_复盘/        每次实战后的偏差、根因与迭代计划
GitHub管理需求.md  仓库范围、脱敏、提交与分支规范
```

## 环境要求

- Windows + SOLIDWORKS 2025（脚本使用 GB 零件模板）
- 脚本通过 VBScript 调用 COM 接口，执行方式：`cscript //nologo build_flange.vbs`
- 无需 Python；PowerShell 的 COM 绑定在本机不可用，不要用

## 已交付模型

脚本从零建模，体积以 `CreateMassProperty2().Volume` 与解析值对比校验。

| 模型 | 关键尺寸 | 理论体积 (mm³) | 实测体积 (mm³) | 偏差 |
|---|---|---|---|---|
| 法兰盘 | D120 / 内孔 d40 / 厚16 / 凸台 φ70×8 / 6×φ14（φ90） | 166806.7 | 166806.0 | 0.0004% |
| 阶梯轴 | φ25×50 / φ40×30 / φ30×70 / φ20×20 / 键槽 12×5×26 | 116540.7 | 116541.0 | 0.0003% |
| 端盖 | D90 / 厚10 / 凸台 φ60×8 / 内孔 d30 / 4×φ9（φ72） | 70968.6 | 70968.6 | 0 |

每个项目目录内的 `.SLDPRT` 为源模型，`.STEP` 为 AP203 交换格式。

## 运行方式

```bat
cd 03_实战项目\01_法兰盘
cscript //nologo build_flange.vbs
```

脚本会把输出文件写到脚本所在目录，并在控制台打印每一步的实测体积与理论值，偏差超过 0.1% 即视为建模错误。
