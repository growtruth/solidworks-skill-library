# SolidWorks 能力基线（环境实测）

> 记录时间：2026-11-08。本文只写“已实测验证”的事实，未验证的一律标注“未验证”。

## 1. 软件环境

| 项目 | 实测结果 |
|---|---|
| 版本 | SOLIDWORKS Premium 2025 SP5.0（API RevisionNumber = 33.5.0） |
| 安装目录 | `D:\FlashGo\sw2025\SOLIDWORKS Corp 2025\SOLIDWORKS` |
| 零件模板 | `C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2025\templates\gb_part.prtdot` |
| 装配模板 | `C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2025\templates\gb_assembly.asmdot` |
| 工程图模板 | 同目录 `gb.drwdot`（GB 图框） |
| Python | 本机无可用 Python（仅 WindowsApps 占位符） |

## 2. 自动化通道可用性（关键结论）

| 通道 | 结果 | 说明 |
|---|---|---|
| VBScript + `CreateObject("SldWorks.Application")` | **可用** | 本机唯一可靠的脚本通道，用 `cscript //nologo xxx.vbs` 执行 |
| PowerShell `New-Object -ComObject` | **不可用** | 访问任何成员都报 `TYPE_E_ELEMENTNOTFOUND (0x8002802B)` |
| PowerShell 加载 `SolidWorks.Interop.sldworks.dll` 强类型转换 | **不可用** | `System.__ComObject` 无法转换为 `ISldWorks` |
| VBScript `GetObject("SldWorks.Application")` | 不可用 | 无法附着已运行实例；直接 `CreateObject` 即可 |

结论：**所有建模脚本统一用 VBScript**，不要再尝试 PowerShell/.NET 路线。

## 3. VBScript 调用的实测坑（会直接影响脚本写法）

1. **带 ByRef 输出参数的 API 无法调用**：`OpenDoc6` 报“类型不匹配”。因此不能靠脚本重新打开已有零件验证，**每个脚本必须从新建文档开始，一次跑完建模+校验+保存**。
2. **`SaveAs2` 返回值不可信**：返回 0（VBScript 中即 False），但文件确实已生成。判断成功与否一律用 `FileSystemObject.FileExists`。
3. **`CreateCircle/CreateLine` 等草图坐标是“草图局部坐标”**，不是模型空间坐标：
   - 前视基准面（XY）草图：直接传 `(x, y, 0)`。
   - 上视基准面（XZ）草图：传 `(x, z, 0)`，第三个参数保持 0（表示在草图平面内，不是法向偏移）。
   - 传错会导致圆形只生成 1 个（其余被判为不在草图平面而丢弃）。
4. **`FeatureCut4` 默认切除方向与草图法线相反**。材料在草图法线正方向时，必须传 `Dir=True`（第 3 个参数）才能切到材料；方向反了会返回 `Nothing`。
5. **函数式调用必须加括号**：`Set c = sm.CreateCircle(0,0,0,0.007,0,0)`。语句式 `sm.CreateCircle 0,0,0,...` 在部分参数组合下会静默失败。
6. **文档名/特征名是中文**（用 GB 模板）：草图是“草图1/草图2”，基准面是“前视基准面/上视基准面/右视基准面”。脚本里通过遍历 `FirstFeature/GetNextFeature` 取 `GetTypeName2()="RefPlane"` 的第 1/2/3 个基准面，避免硬编码中文名。
7. **API 长度单位是米**：100 mm 要写 0.1。
8. `GetBodies2`、`GetSketchSegments` 返回的数组在 VBScript 里 `UBound` 会报错，用 `For Each` 计数，或干脆用质量属性体积判断几何是否正确。

## 4. 已验证的建模能力（可复现）

| 能力 | 调用 | 实测证据 |
|---|---|---|
| 旋转凸台 | `FeatureRevolve2(...)` + 草图内中心线 | 法兰基体 181584.1 mm³（理论 181584） |
| 拉伸凸台 | `FeatureExtrusion2(...)` | 100×60×20 块 120000 mm³ |
| 拉伸切除（通孔） | `FeatureCut4(..., Dir=True, T1=1)` | 6×φ14 通孔后 166806.0 mm³（理论 166806.7） |
| 拉伸切除（双向盲孔，做键槽） | `FeatureCut4(Sd=False, ...)` | 阶梯轴键槽后 116541.0 mm³（理论 116540.7） |
| 保存零件 | `SaveAs2(path, 0, False, False)` | .SLDPRT 正常生成 |
| 导出 STEP | `SaveAs2(path.STEP, 0, False, False)` | ISO-10303-21 / AP203，SolidWorks 2025 生成 |
| 体积校验 | `Extension.CreateMassProperty2().Volume` | 与解析计算逐项对齐 |

## 6. 校验规范（所有模型必须遵守）

1. **体积闭合校验**：先手算解析体积，再与 `CreateMassProperty2().Volume` 对比，偏差 > 0.1% 视为建模错误。
2. **包围盒校验**：用 `GetBoundingBox` 或质量属性确认外形尺寸与图纸一致。
3. **导出校验**：STEP 文件必须存在且首行是 `ISO-10303-21;`。
4. **命名规范**：零件文件名带关键尺寸，如 `flange_D120_d40.SLDPRT`。
